Novablock

Il n'y a volontairement aucun réglage modifiable. La portée est fixée dans le code : Shorts YouTube, reels Facebook et Instagram. Les fils d'actualité, les stories et l'onglet Explorer restent intacts.

Désinstaller

La page des extensions reste librement accessible : vos autres extensions se gèrent normalement. Seule la carte Novablock est verrouillée par la stratégie Windows. Quinze minutes de maintien continu délivrent la commande de retrait.
